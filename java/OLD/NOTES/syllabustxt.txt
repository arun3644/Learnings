Week 1 — Core Java Fundamentals & OOP (Days 1–10)
Day	Topics	Study Plan (3 hours)
1	Java setup, Hello World, Basic program structure	Install JDK & IDE, write simple Java program, data types, variables, literals, keywords (practice small programs)
2	Operators, expressions, if-else, switch-case	Learn all operators, write programs using if-else and switch-case
3	Loops: for, while, do-while	Write programs with all loop types, nested loops practice
4	Classes & Objects basics	Define classes, create objects, instance variables and methods
5	Methods & constructors	Method declaration, overloading, constructors, 'this' keyword
6	Encapsulation & Access modifiers	private, public, protected, default, getter/setter methods
7	Inheritance basics	extends keyword, super keyword, method overriding basics
8	Polymorphism: method overloading & overriding	Practice examples, upcasting, dynamic method dispatch
9	Abstract classes & Interfaces	Abstract methods, interfaces, implements keyword, multiple inheritance via interfaces
10	String class and common methods	String immutability, concatenation, substring, equals, StringBuffer/StringBuilder basics

Week 2 — Exception Handling, Collections & I/O (Days 11–18)
Day	Topics	Study Plan (3 hours)
11	Exception Handling basics	try-catch-finally, multiple catch blocks, nested try, throw vs throws
12	Checked vs unchecked exceptions & Custom exceptions	Create custom exceptions, practice throwing and handling
13	Collections Framework overview & List (ArrayList, LinkedList)	Learn Collection interface, List interface, ArrayList and LinkedList usage
14	Set interface (HashSet, TreeSet)	HashSet and TreeSet differences, use cases, practice problems
15	Map interface (HashMap, TreeMap)	HashMap and TreeMap, key-value basics, common methods
16	Iterators and for-each loop	Use Iterator, ListIterator, enhanced for loop practice
17	Comparable and Comparator interfaces	Implement sorting with Comparable and Comparator
18	Java I/O basics	File handling, InputStream/OutputStream, Readers/Writers

Week 3 — Multithreading, Java 8 Features & JDBC (Days 19–25)
Day	Topics	Study Plan (3 hours)
19	Multithreading basics	Thread class, Runnable interface, create and run threads
20	Thread lifecycle, synchronization basics	Thread states, synchronized keyword, thread safety basics
21	Thread communication	wait(), notify(), notifyAll(), simple producer-consumer example
22	Java 8 Lambda expressions basics	Lambda syntax, functional interfaces, simple examples
23	Functional interfaces & Streams basics	Predicate, Consumer, Function interfaces, Stream API intro
24	Method references & common Stream operations	map, filter, collect, forEach examples
25	JDBC basics	JDBC architecture, database connection, Statement and ResultSet basics

Week 4 — Best Practices, Interview Patterns & Mini Project (Days 26–30)
Day	Topics	Study Plan (3 hours)
26	Java best practices	Code conventions, exception handling best practices, memory management basics
27	Collections effective use & Garbage Collection	Tips for collection usage, overview of garbage collector
28	Common interview coding patterns	Array and String manipulation, searching, sorting algorithms basics
29	Recursion basics and simple data structures	Recursive problems, Stack, Queue, LinkedList (conceptual and basic code)
30	Mini project: CRUD console app	Use collections, exception handling, JDBC connection, multithreading demo
