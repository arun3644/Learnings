🚀 Node.js Complete Course (Zero → Advanced)
1. Introduction to Node.js

What is Node.js?
→ Runtime environment for JavaScript, built on Chrome’s V8 engine, for running JS outside the browser.

Why use Node.js?
→ Non-blocking, event-driven, perfect for scalable apps.

Install Node.js and npm (Node Package Manager).

Run your first script:

console.log("Hello Node.js!");

2. Node.js Fundamentals

Modules

Core Modules: fs, http, path, os, events

Custom Modules: module.exports, require

Example:

// math.js
module.exports.add = (a, b) => a + b;

// app.js
const math = require('./math');
console.log(math.add(5, 3)); // 8


NPM basics

3. File System (fs) Module

Read, write, update, delete files.

Example:

const fs = require('fs');

fs.writeFileSync("data.txt", "Hello World!");
const data = fs.readFileSync("data.txt", "utf8");
console.log(data); // Hello World!

5. Events and EventEmitter

Core of Node.js (everything is event-driven).

const EventEmitter = require('events');
const emitter = new EventEmitter();

emitter.on('greet', () => {
  console.log("Hello from EventEmitter!");
});

emitter.emit('greet');

6. HTTP Module (Build Your Own Server)

Create server

Handle routes (/, /about, /contact)

Send HTML responses

const http = require('http');

const server = http.createServer((req, res) => {
  res.setHeader('Content-Type', 'text/html');
  if (req.url === '/') res.end("<h1>Home Page</h1>");
  else res.end("<h1>Page Not Found</h1>");
});

server.listen(3000, () => console.log("Server running on port 3000"));

7. Streams and Buffers

Large data handling

File streaming

const fs = require('fs');

const readStream = fs.createReadStream("bigfile.txt", "utf8");
readStream.on("data", chunk => {
  console.log("Chunk received:", chunk);
});

8. Asynchronous Programming

Callbacks

Promises

Async/Await

const fs = require('fs').promises;

async function readFile() {
  try {
    const data = await fs.readFile("data.txt", "utf8");
    console.log(data);
  } catch (err) {
    console.log(err);
  }
}
readFile();
